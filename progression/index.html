Escape the Beaver progression route

Move through the current completion goals in a clear order without guessing mode rules or collectible locations.

01

1. Complete the game for First Win

Start with the standard escape objective: search for the vehicle parts needed to progress, survive and hide when threatened, share searched areas, and finish the game. Completion awards First Win.

First Win is the cleanest proof that you understand a complete run. Make it the base for every later challenge.
02

2. Find all 10 notes for Heartbreak

After a first completion, make the notes their own goal. The official badge requires all 10 notes on the map, but its text does not say whether they must be collected in one run. Do not plan around a single-run requirement that has not been confirmed.

Exact note locations are not published here because they were not reliably verified.

03

3. Complete Nightmare Mode

The current badge list confirms a completion badge for Nightmare Mode. It does not describe the mode's rules, so approach it as a later completion target after the basic escape loop is familiar and read the current in-game prompts for details.

04

4. Complete all 12 Bucky Doom rounds

The “Complete Bucky Doom!” badge requires all 12 rounds. Its official description says completion also grants a free invisible skin.

No current official source used here explains each round's task or how to equip the reward, so this route stops at the verified completion requirement.
